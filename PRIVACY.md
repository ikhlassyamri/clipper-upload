# Privacy Policy — clipper-upload

**Last updated: 7 August 2026**

## 1. Overview

`clipper-upload` ("the Application") is a **personal, single-user automation script**
created and operated by an individual creator. It is **not a public service**. It has
no sign-up, no user accounts, no user interface accessible to others, and it is not
distributed, sold, or made available to any third party.

The Application is used by its author for one purpose only: to upload short-form
videos that the author produced themselves to the author's own YouTube channel, and
to read the performance statistics of those same videos.

**The only person who uses the Application is its author.**

## 2. Data We Collect From Users

**None.**

Because the Application has no users other than its author, it does not collect,
request, receive, or process personal data belonging to any other person. It does not
ask anyone to sign in, and it cannot be authorized by anyone other than its author.

## 3. Access to Google / YouTube User Data

The Application uses **YouTube API Services**. It accesses the author's own Google
account through OAuth 2.0, using only the following scopes:

| Scope | Purpose |
|---|---|
| `https://www.googleapis.com/auth/youtube.upload` | Upload the author's own videos to the author's own channel |
| `https://www.googleapis.com/auth/yt-analytics.readonly` | Read view and retention statistics of the author's own videos |

What the Application does with this access:

- **Uploads** video files created by the author to the author's own YouTube channel
  (approximately one video per day).
- **Reads** aggregate statistics of the author's own videos (views, average view
  percentage, average view duration, likes, comments, shares, subscribers gained) so
  the author can evaluate and improve their own content.

What the Application does **not** do:

- It does not access, download, copy, modify, or republish videos belonging to anyone
  else.
- It does not read, store, or process data about YouTube viewers, subscribers, or any
  other individual.
- It does not display YouTube content on any website, application, or platform outside
  of YouTube itself.
- It does not use YouTube data for advertising, profiling, or any form of targeting.
- It does not sell, rent, share, or transfer any data to third parties.

## 4. Storage and Retention

The OAuth refresh token belonging to the author is stored as an encrypted secret in
the author's own private automation environment. It is never written to logs, never
committed to any repository, and never shared.

The statistics retrieved from the YouTube Analytics API are stored only in the
author's own private files and are used solely by the author to review the performance
of their own videos. This data is never published or transmitted anywhere else.

No data belonging to any other person is stored, because none is ever collected.

## 5. Third Parties

The Application shares data with **no third parties**. There are no analytics
providers, advertising networks, data brokers, or external processors involved.

## 6. Revoking Access

Since the only authorized account is the author's own, the author may revoke the
Application's access at any time at:

https://myaccount.google.com/permissions

Revoking access immediately and permanently ends the Application's ability to upload
videos or read statistics.

## 7. YouTube API Services

The Application uses YouTube API Services. By using it, its author is bound by the
[YouTube Terms of Service](https://www.youtube.com/t/terms).

Information handled through YouTube API Services is also governed by the
[Google Privacy Policy](https://policies.google.com/privacy).

## 8. Children

The Application is not directed at children and is not usable by anyone other than its
author. It collects no data from anyone, including children.

## 9. Changes to This Policy

If this policy changes, the updated version will be published at this same URL with a
new "Last updated" date.

# Kebijakan Privasi — clipper-upload (Bahasa Indonesia)

`clipper-upload` adalah **skrip otomatisasi pribadi untuk satu pengguna**, yaitu
pembuatnya sendiri. Aplikasi ini bukan layanan publik: tidak ada pendaftaran, tidak
ada pengguna lain, tidak didistribusikan, dan tidak dijual.

**Aplikasi ini tidak mengumpulkan data pribadi siapa pun.** Karena tidak ada pengguna
selain pembuatnya, tidak ada data orang lain yang diminta, diterima, atau diproses.

Aplikasi mengakses akun Google milik pembuatnya sendiri melalui OAuth 2.0 dengan dua
izin: mengunggah video ke channel YouTube miliknya sendiri, dan membaca statistik
video miliknya sendiri (jumlah tayangan, retensi, durasi tonton rata-rata, suka,
komentar, bagikan, pertambahan subscriber).

Aplikasi **tidak** mengakses, mengunduh, menyalin, atau menerbitkan ulang video milik
orang lain; **tidak** menyimpan data penonton atau subscriber; **tidak** menampilkan
konten YouTube di platform mana pun di luar YouTube; dan **tidak** membagikan data apa
pun kepada pihak ketiga.

Token OAuth milik pembuat disimpan sebagai secret terenkripsi di lingkungan
otomatisasi pribadinya, tidak pernah ditulis ke log maupun ke repositori mana pun.
Akses dapat dicabut kapan saja melalui https://myaccount.google.com/permissions.

Aplikasi ini menggunakan YouTube API Services dan tunduk pada
[Persyaratan Layanan YouTube](https://www.youtube.com/t/terms) serta
[Kebijakan Privasi Google](https://policies.google.com/privacy).
